# Don't Forget

A simple Foundry VTT module for players and GMs to create and manage reminders.

## Features

- Create, edit, and delete reminders
- Mark reminders as completed
- GMs can see all reminders from all players
- GMs can see who created each reminder
- Clean, user-friendly interface
- Integrates with Foundry's UI

## Installation

1. In the Foundry VTT setup screen, go to the "Add-on Modules" tab
2. Click "Install Module"
3. Enter the following URL in the "Manifest URL" field:
   `https://github.com/Sayshal/dont-forget/releases/latest/download/module.json`
4. Click "Install"
5. Activate the module in your world

## Usage

- Click the "Reminders" button in the player list to open the reminder interface
- Create new reminders with the "Add Reminder" button
- Click the checkbox to mark a reminder as completed
- Use the edit button to modify a reminder's text
- Use the delete button to remove a reminder
- "Delete Completed" removes all reminders marked as done
